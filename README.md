# HolyPerformative (HP)

> An aesthetic, editorial graphic ID card design studio and high-resolution print generator.

---

## ✨ Features

- **8 Curated Card Themes**: Editorial passports, creative portfolio passes, travel licenses, and holographic ID templates.
- **Interactive 3D Card Flipping**: Flip seamlessly between the front and back of any card.
- **Direct Live In-Place Customization**: Tap any text field, badge, serial code, photo, or statement directly on the card to edit.
- **Custom QR Code Generator**: Generate crisp vector QR codes for Instagram, Spotify, TikTok, or portfolios and place them as draggable stickers.
- **Custom Graphics & Text**: Add draggable stickers, badges, and custom text with curated typography (Space Mono, Outfit, Cinzel Decorative, Playball, Press Start 2P, etc.).
- **Photo Upload & Filters**: Upload custom portraits with customizable border and corner radius settings.
- **Offline High-Resolution Dual Print Sheet**: Export full-resolution front and back CR80 standard cutout sheets with crop guidelines.
- **Auto-Persistent Sessions**: Work progress is automatically saved to browser storage.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Export & Rendering**: `html-to-image` + HTML5 Canvas
- **QR Code**: `qrcode` (SVG)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/HolyPerformative.git
cd HolyPerformative
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:3000/`.

### Production Build

```bash
npm run build
```

The build artifacts will be output to the `dist/` directory, ready for deployment to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
