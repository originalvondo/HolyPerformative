# HolyPerformative (HP)

> An aesthetic, editorial graphic ID card design studio and high-resolution print generator.

---

## Features

- **Card Themes**: Editorial ID templates.
- **Direct Live In-Place Customization**: Tap any text field, badge, serial code, photo, or statement directly on the card to edit.
- **Custom Graphics & Text**: Add draggable stickers, badges, and custom text with curated typography 
- **Offline High-Resolution Dual Print Sheet**: Export full-resolution front and back CR80 standard cutout sheets with crop guidelines.
- **Auto-Persistent Sessions**: Work progress is automatically saved to browser cache. 

---

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/HolyPerformative.git
cd HolyPerformative
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:3000/`.

### Production Build

```bash
npm run build
```

The build artifacts will be output to the `dist/` directory, ready for deployment to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
